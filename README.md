# SelfDev — Clarity Lab

This repository hosts an original, private, offline communication-skills Android app.

The intended source consists of a single standalone HTML application, an Android Java WebView wrapper, a source archive, a manual-only debug APK GitHub Actions workflow, and verification evidence.

No paid services, live deployment, automatic workflows or third-party content access are required. The release gate is a signed and inspected Android debug APK followed by device testing.
